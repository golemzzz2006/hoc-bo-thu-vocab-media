# hoc-bo-thu-vocab-media

Zero-weight static media CDN repository for **Học Bộ Thủ & HSK 1–6** (`golemzzz2006/hoc-bo-thu`).

- `img/hsk1..6/*.webp`: Compressed WebP vocabulary illustrations (420px max width).
- `audio/hsk1..6/*.mp3`: Native Mandarin vocabulary audio clips.

Served globally via jsDelivr CDN (`https://cdn.jsdelivr.net/gh/golemzzz2006/hoc-bo-thu-vocab-media@main/...`).
